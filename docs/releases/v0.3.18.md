# nginx-web for fnOS v0.3.18

本次更新汇总 v0.3.12 之后的规则编辑与界面优化，内置 Nginx 1.30.4。

## 更新内容

- HTTP(S) 与 TCP/UDP 规则采用分类选项卡，切换时保留输入，校验失败时定位对应分类与字段。
- 分类导航与表单滚动区域分离，避免标签遮挡字段；底部固定“取消”和“保存并应用”。
- 默认路径处理方式提供反向代理、静态文件、返回 / 跳转快捷选项，其他协议通过菜单选择，并显示用途说明。
- 统一规则编辑器的字段、分组标题和内容对齐，收紧输入框与多行文本框尺寸，保留手动拉高能力。
- 压缩各类弹窗的标题栏、图标、操作按钮及上下留白；单行标题栏约 44px，代理规则底栏约 43px，带说明文字的标题栏按内容增高。
- HTTP(S)、TCP/UDP、转发服务组、限流策略和证书页面顶部操作按钮统一为 30px 高、13px 字号，保留窄屏换行。
- 规则启停显示正在处理的目标状态，提交期间禁用重复操作，完成后刷新确认状态。

## 安装包选择

| 架构 | 标准版 | 全端口版 |
| --- | --- | --- |
| x86_64（Intel / AMD） | `nginx-web-0.3.18-standard-x86_64.fpk` | `nginx-web-0.3.18-full-ports-x86_64.fpk` |
| ARM64 | `nginx-web-0.3.18-standard-arm64.fpk` | `nginx-web-0.3.18-full-ports-arm64.fpk` |

- 标准版监听端口范围为 **1024–65535**；需要直接监听 80、443 等低端口时选择全端口版。
- 全端口版监听端口范围为 **1–65535**，端口仍须未被其他服务占用。两版使用相同应用标识，选择其中一种安装。
- 升级前可在“备份与恢复”中导出配置；备份包含私钥，请妥善保管。配置备份不包含 ACME 账户、DNS 凭据和自动续期任务，不能替代这些数据的迁移备份。
- 下载对应 `.sha256` 或汇总 `SHA256SUMS.txt` 校验安装包。

## 验证范围

- standard / full_ports Go 测试、fnOS 前端类型检查和两种权限模式构建通过。
- 四个 FPK 的版本、架构、权限模式、生命周期结构、干净核心提交来源及 SHA-256 校验通过。
