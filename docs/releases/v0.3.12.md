# nginx-web for fnOS v0.3.12

本次更新完善 ACME 证书申请的日志、配置编辑、DNS 诊断和失败重试，便于定位证书申请失败的原因。以下内容汇总上一次公开版本 v0.3.9 之后的改进。

## 新增

- **申请日志与导出**：查看申请、续期检查和部署重试的执行阶段、结果及耗时。每个任务保留最近 **20 次执行，每次最多 200 条**，应用重启后仍可查看。
- **DNS 排障信息**：记录验证域名、DNS 服务器、检查次数和耗时，区分超时、REFUSED、SERVFAIL、未查到 TXT 和 TXT 值不匹配，并给出处理建议。重复查询状态按间隔记录，达到上限时显示省略数量。
- **配置编辑**：失败或暂停的任务可直接修改，无需删除重建。已保存凭据支持保留、替换或明确清除；“保存配置”按原计划检查，“保存并重试”提交执行。
- **独立 ACME DNS**：为证书任务配置独立 DNS，减少局域网通配符解析对 TXT 验证的干扰；不修改 NAS 系统 DNS。
- **只读配置诊断**：检查 DNS 凭据格式、CA 连通性和 TXT 查询通路，不创建订单、写入 DNS 或部署证书。此检查不能提前确认 API 权限、EAB 有效性或本次 TXT 验证值匹配。
- **固定等待高级选项**：可等待指定时间后提交 CA 验证，仅跳过本地预检查，仍需创建公网 TXT 并通过证书机构的独立验证。

## 改进与修复

- 失败原因以错误状态显示，TXT 清理结果单独保留，避免“已清理”覆盖实际失败阶段。
- 区分“重试申请 / 立即续期”和“重试部署”。部署重试复用已签发证书，重新签发或部署失败时继续使用旧证书。
- 遵守 CA 返回的限流等待时间，显示自动重试时间和手动重试冷却；编辑并重试、重新签发及暂停后恢复不能绕过限流。
- 修复编辑弹窗内下拉菜单无法通过鼠标选择的问题，移除重复的配置修改影响提示。

## 安装包选择

四个安装包均为 **0.3.12**，内置 **Nginx 1.30.4**。

| 架构 | 标准版 | 全端口版 |
| --- | --- | --- |
| x86_64（Intel / AMD） | `nginx-web-0.3.12-standard-x86_64.fpk` | `nginx-web-0.3.12-full-ports-x86_64.fpk` |
| ARM64 | `nginx-web-0.3.12-standard-arm64.fpk` | `nginx-web-0.3.12-full-ports-arm64.fpk` |

- 标准版支持监听 **1024–65535**；需要直接监听 **80、443** 等低端口时选择全端口版。
- 全端口版支持监听 **1–65535**，端口仍需未被系统或其他应用占用。两版使用相同应用标识，请选择其中一种安装。
- 建议升级前在“备份与恢复”中导出配置。升级前未记录的 ACME 历史过程无法补录。
- 日志不记录或导出 DNS API 密钥、证书私钥和 TXT 验证值。

## 验证范围

- standard / full_ports Go 测试、fnOS 前端类型检查与构建通过；编辑、日志、诊断等流程通过本地浏览器检查。
- 四个 FPK 的版本、架构、权限模式、核心来源及 SHA256 校验通过。
- ARM64 标准版和全端口版通过隔离 Linux 容器的安装、启停、保留数据恢复及卸载测试。
- ARM64 标准版通过隔离 Linux 容器的 HTTP / HTTPS 代理集成测试。
- x86_64 未进行运行验证；尚未进行真实 fnOS 安装或升级验证。
